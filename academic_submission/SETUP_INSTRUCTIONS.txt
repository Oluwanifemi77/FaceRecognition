═══════════════════════════════════════════════════════════════════
STEP 7: DEPLOY TO HOSTING PLATFORM
═══════════════════════════════════════════════════════════════════

OPTION A - RENDER.COM (Recommended):

1. Go to https://render.com
2. Sign up with GitHub
3. Click "New" → "Web Service"
4. Select your repository
5. Settings:
   - Name: emotion-detection-app
   - Environment: Python 3
   - Build Command: pip install -r requirements.txt
   - Start Command: gunicorn app:app
6. Click "Create Web Service"
7. Wait for deployment (5-10 minutes)
8. Copy your URL (e.g., https://your-app.onrender.com)

OPTION B - RAILWAY.APP:

1. Go to https://railway.app
2. Sign up with GitHub
3. New Project → "Deploy from GitHub repo"
4. Select your repository
5. Railway auto-deploys
6. Click "Generate Domain"
7. Copy your URL

STEP 9: TRAIN MODEL (OPTIONAL BUT RECOMMENDED)
═══════════════════════════════════════════════════════════════════

For better accuracy:

1. Download FER2013 dataset from Kaggle
2. Place fer2013.csv in this folder
3. Edit model.py (uncomment line 281)
4. Run: python model.py
5. Wait for training (30-60 minutes)
6. model.h5 will be created

Without training, app uses demo predictions.

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Problem: "Module not found"
Solution: pip install -r requirements.txt

Problem: "Port already in use"
Solution: Use different port: python app.py (edit app.py line 347)

Problem: "No faces detected"
Solution: Use clear, front-facing images with good lighting

Problem: "Model not found warning"
Solution: Either train model or ignore (app works with demo)

Problem: Webcam not working
Solution: Allow browser camera permissions, use HTTPS for production
